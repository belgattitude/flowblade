Flowblade provides typed datasource adapters with a consistent API for query
results, errors, metadata, streaming and transactions. Use Kysely with your
database, or use DuckDB directly for local analytics and data processing.

Choose the adapter that fits your database: Kysely reuses your configured
Kysely instance and dialect; DuckDB uses `@duckdb/node-api` and Flowblade's
`sql` template tag. Both adapters share the core query, result, error and
transaction contracts.
